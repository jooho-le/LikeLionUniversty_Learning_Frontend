HyperUI는 Tailwind CSS용 무료 오픈소스 UI 컴포넌트 모음 사이트임.
쉽게 말하면 버튼, 카드, 폼, 헤더, 로그인 화면 같은 UI 코드를 복붙해서 바로 쓰는 템플릿 라이브러리라고 보면 됨.

특징은 이럼.

설치형 프레임워크라기보다 컴포넌트 코드를 복사해서 내 프로젝트에 붙여 넣는 방식임.
Tailwind CSS v4 기반으로 만들어져 있어서, Tailwind를 쓰는 프로젝트에서 특히 편하게 씀. 현재 공식 FAQ 기준으로 v4.2 호환이라고 안내됨.
HTML 기반이라서 순수 HTML 프로젝트, React, Vue, Next.js 같은 데에도 응용 가능함.
마케팅 페이지용, 앱 화면용, 네오브루탈리즘 스타일 등으로 카테고리가 나뉘어 있음.
